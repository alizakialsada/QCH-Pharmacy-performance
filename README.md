# Pharmacy Performance Intelligence V35 — Benchmark Control

Adds employee-level benchmark control to the V34 employee scoring profiles.

For every KPI you can set Weight % and choose: Top employee, Top 3 average, Fixed target, or Manual score.

Dispensing is benchmarked pharmacy-by-pharmacy within the employee home hospital and then weighted by the employee own pharmacy share. Top 3 average uses the three highest positive eligible values. Fixed target uses Actual / Target capped at 100%. Manual score directly uses the entered 0–100 score. STAT defaults to a fixed target of 100% compliance.

The selected rules are used on screen and in employee PDF/Excel exports.
