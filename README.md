# Pharmacy Performance Intelligence V36 — Manager Targets

- Admin controls KPI weights and operational/administrative split only.
- Each employee target is owned by the direct manager in Employee Master (`reports_to`).
- Manager Targets page only lists direct reports for the selected manager.
- KPI achievement = Actual / Manager Target × 100, capped at 100%.
- Missing target for any weighted KPI makes Operational Score pending; weights are never redistributed.
- STAT target is a compliance percentage target; other targets are activity counts.
- Target owner and last update are shown in employee views and exports where applicable.
- PDF and Excel export buttons are preserved.
